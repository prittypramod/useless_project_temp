# Workspace Rules: rage-typing

## Repository Details
- **Git Remote**: `https://github.com/prittypramod/rage-typing.git`
- **Default Branch**: `main`

## Git Synchronization Protocols
1. **Pull Before Updating**:
   - Before applying updates or modifications to the codebase, always run `git pull origin main` (or `git pull`) to ensure the local workspace has the latest remote changes.
2. **Push After Updating**:
   - Whenever repository files are created, updated, or modified, stage the changes (`git add .`), create a meaningful commit message (`git commit -m "..."`), and push to git (`git push origin main`).
3. **Repository Persistence**:
   - Always remember and maintain connection to `https://github.com/prittypramod/rage-typing.git` for this workspace.
